# V33 外壳归档

`cad/DASHAN_V33.blend`：可编辑装配副本，保留 67 个网格物件（含辅助/试配样件）和 27 个打印件；从新场景导入几何，删除外部库记录、自定义元数据、图片与嵌入脚本。文件位置元数据改为中性相对名称并压缩保存，重新载入核验所有网格和变换与原稿一致。未改原装配或零件尺寸。使用 Blender 5.2.2 核验。

`stl/`：27 个独立零件，单位 mm。分别导入切片软件，按平台分盘，检查朝向、支撑和接触面。不要把网页 GLB 当作打印模型。

V33 基于 V30：只更换底座，正面看左侧靠后预留 USB-A 孔，右侧保持完整。
孔 13 × 6 mm、圆角 R1；孔中心距底面 11 mm、距最后端 13 mm。
`v33-check.json` 是原设计的开孔核验记录，不代表整机实物装配验收。
`previews/base-usb-left.png` 为开孔预览。

屏幕载架为 `33_LCD183_carrier.stl`，屏幕嵌入机身顶部开口。
接口模块固定座尚未设计，需实际试装；螺丝孔与螺丝长度也需按实物复核，不能将旧讨论视为全部验证完成。
USB 接口不能直接接电池电芯。电源接线说明见 `../docs/HARDWARE.md`。
