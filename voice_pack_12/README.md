# 侦探相机预设语音

**当前 MP3 为私有试验归档，不在项目 MIT / CC BY 4.0 许可范围内，也不随未来公开版本分发。**
参赛和公开演示需使用原创或已明确许可的声音，不能把第三方真人/角色音色当作可自由再分发素材。此目录保留阶段与命名约定，方便替换。

`filesystem/voice/` 内是固件使用的 MP3 文件：

- `01–04_shutter.mp3`：拍摄后开始观察。
- `05–08_wait.mp3`：等待期间的侦探式思考。
- `09–12_printing.mp3`：生成完成、准备出卷。
- `report.mp3`：存在时优先用于出报告阶段。

此仓库只保存音频，不包含设备 Flash 镜像。不要把旧版整盘镜像刷进新设备；
应按固件实际分区配置构建文件系统，或在固件支持的情况下直接复制到存储卡。
这份固件当前通过 FFat 访问 `/voice/`，仅复制到 SD 卡不会自动生效。

USB 串口发送 `w` 可执行预设语音自测，不触发拍摄、AI 或打印。
发送 `v` 可在预设流程之后继续播放已保存的案件朗读。

替换时保持上述文件名，核验解码、采样率、音量和句尾，分别测试快门、等待、出卷阶段；不要用截断对白来适配固定等待时间。公开包不提供现有配音文件，但应提供合规替代或经验证的降级方式，详见 `../docs/RELEASE_CHECKLIST.md`。
