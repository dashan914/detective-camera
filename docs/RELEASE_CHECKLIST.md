## 发布操作

1. 保留此私有归档；**不要直接将其改成 public**，历史提交中仍有试验配音。
2. 运行 `python3 tools/privacy_check.py --history` 与 `python3 tools/public_release_check.py`。后一项会报告授权/复现待办，不把隐私扫描当授权确认。
3. 用核准清单导出新的文件树；不携带 `.git`、MP3、私人运行数据或当前文学库。未确认许可的驱动不得悄悄混入。
4. 完成声音/文学库替代和驱动核验，重新构建、测试并记录新版本。单纯排除这些文件会影响复现，不能把残缺包称作完整版本。
5. 只有得到项目维护者新的明确发布指令，才创建公开仓库/Release 或上线新版。
