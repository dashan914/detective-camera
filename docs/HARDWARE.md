# 接线与装配索引

以仓库内固件定义为准；接线前断电并核对丝印，不凭线色判断。

| 模块 | 当前固件连接 |
| --- | --- |
| 主板 | Waveshare ESP32-S3-CAM-OV5640，16 MB Flash / 8 MB OPI PSRAM |
| MY-628 热敏打印 | GPIO43 TX → 打印机 RX；GPIO44 RX 接返回信号前核对逻辑电平；9600 8N1，GND 共地 |
| I²C 共享总线 | SDA GPIO8 / SCL GPIO7，供相机、音频控制与扩展芯片使用 |
| MCP23017 快门 | 地址 0x27；PB0 输入上拉，按钮接 PB0 与 GND；按下为低电平，20 ms 消抖 |
| 扬声器 | 主板 SPK 座子（资源图编号 14），不是接到 GPIO14；由 ES8311 和板载功放驱动 |
| 1.83 英寸触摸 LCD | 固件 ST7789 驱动，284×240；MOSI 1 / CLK 5 / DC 3 / CS 6，板载扩展 IO 控制复位和背光 |

屏幕目前实现显示和表情，不据此声称触摸操作已验证。扩展板供电使用与 ESP32 兼容的 3.3 V 并共地；若地址不是 0x27，需要调整地址配置或固件，不能插上即假定工作。

电源：不要把 7.4 V 电池或降压后的 5 V 接到单节锂电 BAT 座子（资源图编号 15）。BAT 用于单节 3.7 V 锂电；5 V 稳压电源应走 USB 供电路径。打印机必须按其规格独立供电，不能从 ESP32 的 3V3 引脚供电。DTR 是流控信号，不是电源，勿直接接 3V3。

装配：前面板 → 镜头/相机载架 → 顶部屏幕载架 → 按钮导向和开关座 → 打印模块和纸轴 → 电池及底座 → 后壳。先干装检查排线弯曲半径、纸路、USB 开孔和螺丝长度，再紧固。当前归档没有可靠的最终螺丝 BOM，不编造数量/长度。

固件编译/配网见 `../firmware/README.md`，待机策略见 `../firmware/STANDBY.md`。
