# 项目结构与体验

侦探相机不是现实鉴定工具。照片事实和虚构案情分开呈现，案卷注明「线索来自照片 · 案情纯属虚构」。

1. 快门：ESP32 拍摄 JPEG，立即播放本地观察语音。
2. 传输：设备带独立令牌上传照片到后端，导演台可显示状态与最近照片。
3. 推理：后端调用配置的模型，输出案件名、案情、照片线索、关键证据、推测还原和口述稿；本地检查字段及逻辑。
4. 等待：ESP32 根据实际耗时衔接侦探自言自语，屏幕进入思考表情；不强行截断正在说的句子。
5. 出案卷：后端把照片和文字渲染为 384 点位图，设备通过 UART 光栅打印。可选 TTS 生成同一案件的 MP3。

模型分析输出文字/JSON，不生成照片；票面照片来自实拍的黑白处理。TTS 失败有独立状态，不应使已排队打印失效。

`demo/` 是静态产品演示：使用固定示例案件和四个已生成音频，模拟流程，不调用 AI、不上传照片、不驱动真实打印机。屏幕动画源于固件绘图，3D 模型源于 V33 装配。

历史目录名含 Poetry，但当前核心体验为侦探相机；文学匹配及手动诗票仍保留。新部署首次配置时请在导演台选择侦探模式，勿直接恢复带 Key 的旧状态文件到 Git。
